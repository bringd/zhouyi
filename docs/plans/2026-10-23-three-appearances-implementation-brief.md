## 2. 外观选择与记忆

正式界面统一使用“外观”作为功能名称，不出现“方案 A/B/C”“设计实验室”等提案措辞。

1. 设置页新增“外观”区域，用三张可选择卡片展示名称、缩略图或色彩示意、简短说明、当前选中态。
2. Header 提供“外观”快捷入口，能展开三个选项；桌面和手机均可操作。设置页与快捷入口共用同一状态。
3. 点击即生效，无需刷新、无需再次保存。选中态不能只靠颜色表达。
4. 刷新、关闭再打开、直接进入任意正式路由，仍保持此前选择。
5. 没有偏好、偏好值非法或旧版本缺少该字段时，默认 A。用户明确选择后，不再被系统深浅色偏好覆盖。
6. 存储不可用时，仍可在当前会话切换，并以非阻塞方式说明无法记住偏好。
7. 冷启动与刷新不能出现明显的浅色闪屏，尤其已选择 C 时。
8. 键盘可以打开选择器、选择、关闭并返回触发位置；选中状态有正确语义。若使用弹层，实现相应焦点管理。

实施建议：在现有 UserSettings 中增加独立的 appearance 字段，稳定值可用 qinglan / zhusha / yehang；保留现有 theme: 'light' 的兼容含义，不直接扩展它来混装三种风格。读取时对新字段做白名单校验，写入时保留其他设置。复用 src/lib/storage.ts 的防御式读写约定。

## 3. 切换外观不能影响正在做的事

外观切换是展示变化，不是重新进入页面。不得通过给整个页面加外观 key、强制刷新或重新导航来完成。

必须保留：

- 起卦页已填写的问题、三个数字、校验状态；随机取数的状态转换保持正确。
- 当前结果记录 ID、卦象、动爻位置、已生成的 AI 内容和错误/重试状态。
- AI 请求正在进行时的流式内容；切换不能重复发送请求、截断内容或清空缓存。
- 云端保存、社区发布等操作的进行中与成功状态；切换不能重复执行副作用。
- 当前路由与合理的滚动位置。

切换外观本身不创建记录，不调用 AI，不自动保存云端，不发布社区。

## 4. 正式业务接入要求

- 复用现有三数起卦算法，六爻保持自下而上的约定。
- 首页不固定显示预览中的某个卦，不写死日期或时区。
- 结果页必须根据真实记录渲染问题、数字、本卦、变卦和动爻；不存在的记录仍显示正常回退。
- AI 入口沿用正式鉴权、调用、流式协议、错误码和缓存逻辑。不能把静态示例包装成 AI 回答。
- 保留云端保存的本地/云端状态说明、发布前的问题公开提示及错误反馈。
- PNG 下载保留现有数据和行为。本轮不要求提供三套导出卡片皮肤。
- 不新增后端协议、不向废弃 server/ 增加路由。

## 5. 实现与视觉质量边界

- 三套外观共用一份业务状态和事件处理；可拆展示组件或布局变体，不能复制三份 AI、存储和发布逻辑。
- 颜色、字体、控件与背景通过语义令牌管理。相同角色使用令牌，插画内部颜色可以独立。
- 外观挂在统一根节点，通过稳定的 data 属性或显式 class 生效；不能依赖中文 aria-label 或长链 DOM 结构选择器刷皮肤。
- 保留 A/B/C 的布局区别，不能只替换颜色后声称三套完成。
- 正文建议 14–16px，辅助文字至少 12px；不要为了装进卡片把中文缩到 7–11px。
- 正文、链接、占位提示和关键状态按实际合成背景验收。渐变和山水/星图背景不能只取父元素 background-color 计算对比度。
- 普通有意义文字对比度目标至少 4.5:1，大字至少 3:1；装饰内容需明确区分。
- 独立点击目标优先保证至少 24×24 CSS px，手机主要按钮建议至少 44px 高；结合间距和句内链接例外判断。
- 减少动态效果覆盖 CSS、页面切换、随机数字、JS/Framer Motion；不能只关闭入场动画后就宣布全部通过。
- C 外观应完整检查输入、placeholder、弹层、错误、禁用、加载、缓存解读和 Markdown 内容的可读性。

## 7. 浏览器验收矩阵

### 视觉

- 三种外观 × 首页/起卦/结果 × 1440、1024、768、390、320px。
- 另对图鉴、卦象详情、卦册、社区、设置、404 检查三种外观的共享框架、可读性和操作可用性。
- 桌面真实 200% 浏览器缩放，确认内容仍可读、无关键内容裁切或操作丢失。记录实际缩放方法和 CSS 视口，不得用 deviceScaleFactor=2 冒充浏览器缩放。
- reduce 模式下主动触发随机取数、切换页面等操作，不只检查静态首页。
- 结果页至少检查未解读、加载中、错误/重试、缓存内容四种状态。

### 行为

依次完成：选择 B → 起卦填数 → 切到 C → 启卦 → 切到 A → AI/保存/发布模拟成功或失败 → 刷新 → 查看卦册。

证明输入与记录没有丢失、外观记住选择、动作没有因切换而重复执行。付费 AI 和公开发布可使用明确标注的模拟接口；不得据此声称已通过真实部署联调。

### 证据有效性

- 截图与探针前必须检查导航成功、应用根节点及页面关键内容已出现。
- 连接失败、空白页、Vite 错误遮罩、缺少预置记录的错误结果页均不能当作正常验收截图。
- 不以固定 sleep 和“没有横向滚动条”作为唯一成功条件。
- 对比度检查覆盖实际图片/渐变背景；必要时人工查看文字落点。
- 截图记录外观、页面、视口、场景与时间。图例和示例数据明确标识。
