① 启卦按钮 · 改前 vs 改后

问题：原按钮朱砂红 + opacity-0.6, 视觉上像 disabled, 削弱了"起卦"作为核心 CTA 的仪式感。
方案：渐变朱砂 + 金线描边 + 字距 0.5em + 印泥 inset shadow + 三横 SVG 图标 (呼应卦象三爻), disabled 状态用低饱和古铜而非灰粉。
